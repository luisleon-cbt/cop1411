How this challenge works

  1. Read the symptom: the real output or error the function produced. Then read the code and find the one line that causes it.
  2. Edit the code in the box and press Run. Real Python runs your version and the tests under it. All tests pass on your first Run: 10 points. On a later Run: 6 points.
  3. Stuck? Press Show the fix, read why, and Run it: 3 points.
  4. Press Next round. After round 10, review your results. 90 or more earns confetti.
