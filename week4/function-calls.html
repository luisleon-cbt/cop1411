How to use this lab

  1. Under Pick a function, choose one of the five toolkit functions and its arguments. The charts redraw: MAIN on the left, the function on the right.
  2. Press Step. Watch the token carry the arguments into the parameter boxes, walk the function, and bring the return value back to MAIN.
  3. Press Step back to see a step again, or Run to play every step. Click any symbol to read what it does.
  4. Turn on Copilot's refactor and run the same call. Find the test that catches the bug (the narration names it).
  5. Scroll down to Try it, edit toolkit.py, and press Run there: five tests check your functions on real Python.

Things to notice

      
    
        
  • A def never runs by itself. Nothing inside a function happens until a call symbol names it with arguments.
    • 
        
  • Arguments match parameters by position: the first argument fills the first parameter box. Swap the order and the function computes with the wrong numbers, with no error message.
    • 
        
  • The parameter boxes and the local boxes appear at the call and are deleted at the return. MAIN only ever receives the returned value.
    • 
        
  • return is not print. A function that prints instead of returning hands back None, and MAIN's result box stays empty.
    • 
        
  • A Copilot version that passes one test can still be wrong. The right test is the one that reaches the buggy symbol.
