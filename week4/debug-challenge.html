How this challenge works

  1. Read the function and the test call below it, then read the symptom: the wrong output or the error message Python printed. Error messages name the line; wrong outputs need a trace.
  2. Pick the bad line (4 points) and press Check. The line is then marked on the code whether you were right or not.
  3. Pick the fix for that line (6 points) and press Check again. Read why the best fix is best.
  4. Press Play the explanation to watch the bad value on the board, then the fixed call. Press Next round. After round 10, review your results and press Try again if you want.
