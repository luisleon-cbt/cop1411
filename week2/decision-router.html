How to use this lab

  1. Look at the board: the package enters at the left, passes three diamonds in order (weight, fragile, city), and lands in one of the six lanes at the right. Click a diamond to read its condition and its Python line.
  2. Press Step to move the package one decision at a time. Watch the Decisions table below turn each comparison True or False.
  3. Pick another package in the Package panel (try PP-2026-0006, exactly 50 lb) and press Run. Predict the lane before you press.
  4. Turn on Copilot's order, pick PP-2026-0005 (60 lb, fragile), and run it again. Watch where it lands and read why.

    Things to notice

    • Exactly 50 lb is not above 50: weight > 50 is False, so PP-2026-0006 stays in a van. A boundary value is the first test to write.
    • The chain stops at the first True. In Copilot's order, fragile is True for PP-2026-0005 before the weight is ever checked, so a 60 lb box lands on a shelf meant for light packages.
    • Both orders give the same lane for seven of the eight reference packages. Only the fragile-and-heavy case shows the bug: a test plan needs that row.
    • Comparisons are exact. Type doral (lowercase) as the city and the package goes to ASK DISPATCH, because "doral" == "Doral" is False.
    • The price never depends on the order of the lane checks: the surcharge has its own if before the chain.
