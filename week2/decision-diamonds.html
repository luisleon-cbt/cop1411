How to use this lab

  1. Pick a Reference package below, or type your own weight, miles, city, and fragile answer.
  2. Press Step. The token leaves START and carries each value into the chart. At every diamond, read the comparison and its True or False in the Decisions box.
  3. Press Step back to see a decision again, or Run to play every step. Click any symbol for a plain-language note.
  4. Press Copilot's order, pick package PP-2026-0005, and run again: the token lands on FRAGILE and the narration names the diamond that was never reached. Drag the checks into any order you like and run again.
  5. Scroll down to Try it, change the code, and press Run there to run real Python with three tests.

    Things to notice
    
      
      
        
    • Python runs only the first True branch of an if, elif, else chain. In dispatch order, PP-2026-0005 answers True at weight > 50 and the fragile diamond is never asked.
      • 
        
    • Exactly 50 is not above 50: the comparison 50 > 50 is False, so PP-2026-0006 stays in a van (lane B). A sorter written with >= would send it to FREIGHT.
      • 
        
    • The surcharge decision is separate from the lane chain and has no else, so the price never depends on the order of the lane checks.
      • 
        
    • Seven of the eight reference packages land in the same lane in both orders. Only a test plan with one package per lane, the boundary, and the fragile-and-heavy case shows the difference.
