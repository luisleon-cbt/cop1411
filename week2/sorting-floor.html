      Things to notice
      
      
        
        
      • An if-elif chain runs only the first True branch. Every elif after it is skipped, even when its condition would also be True.
        • 
        
      • The surcharge if on line 7 has no else: when it is False, nothing happens and the price stays as it was.
        • 
        
      • Exactly 50 lb is not above 50. The comparison is >, not >=, so package PP-2026-0006 stays in a van.
        • 
        
      • Copilot's order gives the right lane for seven of the eight reference packages. Only PP-2026-0005 (heavy and fragile) exposes it, which is why a test plan must cover every branch.
        • 
        
      • input() gives text. The city is compared exactly, so "doral" goes to ASK DISPATCH, and the weight needs float() before > can compare numbers.
