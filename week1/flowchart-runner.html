How to use this lab

  1. Pick a package in Package below (or type a weight and miles). Click a symbol on the chart to read what it does.
  2. Press Step to move the token to the next symbol. Watch the memory boxes, the screen, and the lit line of label.py.
  3. Press Step back to see a step again, or Run to play every step. Then open Same algorithm, four ways and Prompt as specification.
  4. Scroll to Try it, change the code or the inputs, and press Run there to run real Python.

Try it: edit and run the Python

This is label.py, the program the chart becomes. The Inputs box types the answers for the two input() calls. Press Run, then change a value or the formula and run again. The two tests under the output check the formula for packages 0001 and 0004.

Things to notice

  • The token carries only what exists so far: a question mark until INPUT weight reads a number, then 12.0, then both values.
  • One PROCESS symbol is one line of Python, but three calculations happen inside it: the weight part, the miles part, and the sum with the base.
  • Memory keeps 16.1; the screen shows 16.10. The two decimals come from the f-string at print time, not from the stored number.
  • input() always gives text. float() turns "12" into the number 12.0. Without float(), 0.80 * weight stops with a TypeError.
  • The precise prompt names every working symbol. The vague prompt leaves four symbols for Copilot to guess, and a guess can be wrong without any error message.
