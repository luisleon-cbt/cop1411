The same algorithm as pseudocode and as Python

Pseudocode plain numbered steps

  1. START
  2. INPUT weight
  3. INPUT miles
  4. price = 4.50 + 0.80 * weight + 0.25 * miles
  5. OUTPUT "Package price: $" and price with two decimals
  6. END

Python 3 label.py

  1. weight = float(input("Weight in pounds: "))
  2. miles = float(input("Miles: "))
  3. price = 4.50 + 0.80 * weight + 0.25 * miles
  4. print(f"Package price: ${price:.2f}")

The current line lights up as you step. Python has no START or END line: the program starts at the first line and stops after the last one.

Write it as a prompt for Microsoft Copilot

A prompt is a specification: it must name the inputs, the steps, and the expected output, the same parts as the flowchart. Pick a prompt and see which symbols on the board it covers.

Press Vague prompt or Precise prompt.
    Click any symbol on the board to learn what it means.

    Things to notice

    • The = sign in price = ... does not mean "equals". It means "compute the right side, then store the result in the box on the left".
    • input() always hands back text. Without float(), 12 + 8 would give 128: the two texts glued together.
    • The variable price keeps 16.1; the label shows 16.10. Formatting changes what you see, not what is stored.
    • A precise prompt covers the same four things as the flowchart: the inputs, the formula, the exact output text, and one worked example.
