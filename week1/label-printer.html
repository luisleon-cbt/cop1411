Flowchart

        
Pseudocode
STARTINPUT weightINPUT milesprice = 4.50 + 0.80 * weight + 0.25 * milesOUTPUT "Package price: $" and price with two decimalsEND

        
Python

        
Copilot prompt
Write a Python 3 program for a delivery company that prints a price label.
Inputs: the package weight in pounds and the miles to the customer, both typed by the user and read as real numbers.
Steps: price = 4.50 + 0.80 * weight + 0.25 * miles.
Expected output: one line, Package price: $16.10, when the weight is 12 and the miles are 8. Show two decimals.

    Things to notice
    
      
      
        
    • input() stops the program and waits. Nothing happens on line 1 until the scale has a weight, the same way IDLE waits for you to type.
      • 
        
    • input() always gives text. The scale shows 12, but the program receives "12"; float() turns it into the number 12.0 so the formula can multiply it.
      • 
        
    • Line 3 is one line of Python but four calculations: two multiplications, two additions, then the = stores the result in price.
      • 
        
    • price holds 16.1. The label shows 16.10 because :.2f formats the text with two decimals. Formatting changes what you see, not what is stored.
      • 
        
    • The flowchart, the pseudocode, the Python, and the precise prompt all have the same six parts. That is why writing the prompt is the same skill as writing the algorithm.
