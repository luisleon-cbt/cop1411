    Things to notice
    
      
      
        
    • The first INPUT happens before the loop, so the test has a value to check. The second INPUT is the last symbol of the body: without it the loop never ends.
      • 
        
    • The sentinel -1 is read, tested, and never processed: the exit row of the trace table keeps the same total and count as the row above it.
      • 
        
    • For VAN-1, heaviest = weight runs 3 times in 5 passes (12, 20, 50). The test is False for 3 and for 45.
      • 
        
    • The for version has no sentinel and no INPUT inside the loop: it stops by itself after the last item. The index version adds i, which runs from 0 to len(weights) - 1.
      • 
        
    • The capacity check comes after the loop. The overload manifest still reads every package: the loop does not stop at 1,200.
