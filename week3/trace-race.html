How this challenge works

  1. Read the loop in the round below. In a trace round, type a value in every cell (one row per pass) and the printed output, before the loop runs.
  2. Press Run (or Check in a question round). The scene above plays the loop, and every cell flips green or red with the real value.
  3. Read the feedback. Press Play the explanation to watch the loop again.
  4. Press Next round. After round 10, review your results and press Try again if you want a better score.
