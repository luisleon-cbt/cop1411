How to use this lab

  1. Look at the board. The loop is drawn as a ring of chips. The VAN-1 manifest (12, 3, 20, 50, 45) is loaded. To try another one, pick it under Manifest below and press Load.
  2. Press Step. The token moves to the next chip on the ring, the narration says what happens with the real numbers, the variable chips change, and the matching Python line lights up in The code.
  3. Keep pressing Step (or press Run to play the whole manifest). Each time the token completes one trip around the ring, the Trace table gets one new row. That row is the proof of what the loop did.
  4. Press Step back any time to see a step again. Press Reset to start the manifest over.
  5. Press for version under Manifest and run it again. The list is filled before the loop and there is no sentinel: the for loop stops by itself when the list runs out. Then press index version: for i in range(len(weights)) counts 0, 1, 2, ... and weights[i] reads the item at that position, so a second list such as fragile[i] can describe the same package (assignment 3.2 uses this).
  6. Read Copilot's explanation. Mark each sentence True or False using your trace table, then press Check sentences. Click any chip on the board to read what it does.

Things to notice

      
    
        
  • total, count, and heaviest all start at 0 before the loop. Row 0 of the trace table shows it. Starting count at 1 would count a package that never arrived.
    • 
        
  • The sentinel -1 is read like any other weight, but the condition weight != -1 fails, so the body never runs for it. It is not counted and not added.
    • 
        
  • The body runs once per package: five packages, five passes, five rows. An empty manifest gives zero passes and the report still prints.
    • 
        
  • The loop never stops because of the capacity. It reads every package; the warning is checked once, after the loop. Exactly 1,200 lb is not above 1,200.
    • 
        
  • The for version does the same work without a sentinel, because the list already knows how many items it has.
    • 
        
  • The index version is the for version with a counter built in: i goes 0, 1, 2, ..., and weights[i] and fragile[i] are the weight and the fragile answer of the same package.
