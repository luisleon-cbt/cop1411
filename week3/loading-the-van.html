Things to notice

      
    
        
  • The sentinel -1 is read like any other value, but the condition on line 6 is False for it, so it is never appended, added, or counted. The exit row proves it: same total and count as the last pass.
    • 
        
  • heaviest only changes when the test on line 10 is True. For the VAN-1 manifest that happens on passes 1, 3, and 4, so line 11 runs 3 times in 5 passes.
    • 
        
  • The for version has no sentinel and no read inside the loop: the list is full before the loop starts, and the loop stops when the items run out.
    • 
        
  • The index version walks i from 0 to len(weights) - 1. weights[i] and fragile[i] describe the same package, which is how two lists travel together.
    • 
        
  • Exactly 1,200 lb is not above 1,200, so the warning does not print. One more pound and it does.
